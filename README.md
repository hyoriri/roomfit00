# ROOMFIT

원룸과 나의 방을 계획하는 반응형 웹사이트입니다.

## 파일 구성
- index.html: 웹사이트 시작 화면
- style.css: PC·모바일 화면 디자인
- app.js: 방 설계, 가구 추천·저장, 마이페이지, JPG 저장 기능
- assets/: 웹사이트에 사용되는 이미지 전체

## 사용 방법
압축을 풀고 index.html을 브라우저로 열면 됩니다.
GitHub에는 ZIP 파일 자체가 아니라 압축을 푼 파일과 assets 폴더를 업로드하세요.
index.html, style.css, app.js, assets 폴더를 같은 위치에 유지해주세요.

별도의 설치나 빌드 과정은 없습니다.
설계보드와 저장한 가구는 같은 기기·브라우저에 저장됩니다. 기존 사이트에서 저장한 개인 설계 데이터는 파일에 포함되지 않습니다.
